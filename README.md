# 🤝 Shared Project Workspace

Welcome! This repository is a shared space for our team to collaborate on files. Anyone with collaborator access can edit files directly from their web browser.

---

## 📝 How to Edit Files via the GitHub UI

You do not need to download anything or use the terminal. Follow these steps to make changes:

1. **Navigate** to the file you want to edit.
2. Click the **Pencil Icon** (✏️) in the top-right corner of the file view to enter edit mode.
3. Make your changes directly in the text editor.
4. When finished, scroll down to the **Commit changes...** box at the bottom.
5. **Write a short summary** of what you changed (e.g., *"Updated step 3 of the instructions"*).
6. Ensure **"Commit directly to the `main` branch"** is selected.
7. Click the green **Commit changes** button to save.

---

## 🛑 Collaboration Rules of the Road

To keep our project organized and prevent overwriting each other's edits, please follow these guidelines:

* **Refresh Before Editing:** Always refresh your browser page right before hitting the pencil icon to make sure you are looking at the absolute latest version.
* **Keep Commits Small:** Try to make and save one specific change at a time rather than holding an edit window open for hours. This minimizes the risk of a "merge conflict."
* **Write Clear Commit Messages:** Avoid leaving the default *"Update filename.md"* message. Briefly state *what* you changed so others can follow along in the project history.
* **Communicate:** If you plan to rewrite a large section of a shared file, drop a quick note to the team first so nobody else tries to edit it at the same time.
